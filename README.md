# kafka-docker-playground-docs

Documentation website for [kafka-docker-playground](https://github.com/vdesabou/kafka-docker-playground), published at https://kafka-docker-playground.io/#/ with [Docsify](https://docsify.js.org) ([docsify-themeable](https://jhildenbiddle.github.io/docsify-themeable/#/) theme).

## Where to edit

**The pages are no longer edited here.** Their sources live in [`docs/` of kafka-docker-playground](https://github.com/vdesabou/kafka-docker-playground/tree/master/docs): open the PR there, together with the change it documents. `scripts/publish-docs.sh` of the main repository copies that folder to `docs/` here. It runs on every push to `master` touching `docs/**` (`update-docs.yml`), every night (`ci.yml`) and when a milestone issue is closed (`update-changelogs.yml`). Any edit made here to a page coming from there is overwritten by the next publication, and a page deleted or renamed there is deleted here too (the list of published files is in `.published-from-kafka-docker-playground`).

| File(s) | Source, in kafka-docker-playground |
|---|---|
| `how-to-use.md`, `how-it-works.md`, `reusables.md`, `tips-and-tricks.md`, `sessions.md`, `reports.md`, `claude-code.md`, `academy.md`, `legacy-java-producer.md`, `sidebar.md`, `_coverpage.md`, `_404.md`, `index.html`, `llms.txt`, `assets/` | `docs/` (hand-written) |
| `playground *.md`, `index.md`, `cli.md`, `cli-pages.js` | generated by `playground update-docs` from `scripts/cli/src/bashly.yml` and `scripts/cli/docs-template/cli-template.md` |
| `content.md`, `badges.md`, `introduction.md` | generated by `playground update-readme` from `docs/content-template.md`, `docs/badges-template.md`, `docs/introduction-header.md`, `docs/introduction-footer.md` and the CI results |
| `changelog.md` | generated by `update-changelogs.yml` from closed milestones |

What stays here, and is edited here: the media (`videos/`, `images/`), the reports gallery (`reports/`), the tapes and scripts that record them (`tapes/`, `scripts/`), and `CNAME` (GitHub Pages serves `main:/docs`).

The HTML reports and screenshots of the reports gallery (`reports/`, `images/reports/`, shown by the hand-written `reports.md`) are generated by `scripts/generate-reports-gallery.sh` from a clone of kafka-docker-playground: rerun it rather than editing the reports by hand.

The clips (`docs/videos/*.mp4`, plus a `.gif` for the two shown in the GitHub README of the main repository) of the introduction, How to Use, Reproduction toolkit and Claude Code pages are recorded with [VHS](https://github.com/charmbracelet/vhs) from the tapes in `tapes/` by `scripts/generate-cli-videos.sh` (see the header of the script: record from a clone at a neutral path, without the private `reproduction-models`). Change a tape and rerun the script rather than recording by hand:

```bash
git -C ../kafka-docker-playground worktree add --detach /Users/Shared/kafka-docker-playground master
KDP_DIR=/Users/Shared/kafka-docker-playground scripts/generate-cli-videos.sh            # all the clips
KDP_DIR=/Users/Shared/kafka-docker-playground scripts/generate-cli-videos.sh diagnose   # one clip
```

The videos of the hand-written `sessions.md` page (🎬 Bite size sessions: `docs/videos/session-*.mp4`, posters in `images/sessions/`) are recorded the same way from the `tapes/session-*.tape` tapes by `scripts/generate-session-videos.sh`, which also adds a scroll through the HTML report the tape generated. A new session is a tape, an entry in the `session_settings` function of the script (report path, scroll steps, page height, docker, and an off-camera setup function when it needs a running example) and a section of `sessions.md` (in `docs/` of kafka-docker-playground). The poster is taken 6 s before the end of the terminal part, where the comments sum up the session:

```bash
KDP_DIR=/Users/Shared/kafka-docker-playground scripts/generate-session-videos.sh               # all the sessions, about 40 min
KDP_DIR=/Users/Shared/kafka-docker-playground scripts/generate-session-videos.sh gc-logs       # one session
```
