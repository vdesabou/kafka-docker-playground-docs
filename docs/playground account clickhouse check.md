# playground account clickhouse check

🩺 Check the ClickHouse Cloud account of the ClickHouse examples (connect-clickhouse-sink, fm-clickhouse-sink)

Read-only, a few seconds: a SELECT over HTTPS (it also wakes an idle service up). Each failure says why (services idle when unused, trials end...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account clickhouse check
```

## Examples

```bash
playground account clickhouse check
```
