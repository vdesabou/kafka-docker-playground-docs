# playground account couchbase check

🩺 Check the Couchbase Capella account of the Couchbase examples (fm-couchbase-sink, fm-couchbase-source)

Read-only, a few seconds: the cluster state and its allowed IPs through the Capella API. Each failure says why (free tier clusters are turned off after 72 hours without use: setup turns them back on...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account couchbase check
```

## Examples

```bash
playground account couchbase check
```
