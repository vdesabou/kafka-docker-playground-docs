# playground account jira check

🩺 Check the Jira account of the Jira examples (connect-jira-source, fm-jira-source)

Read-only, a few seconds: the login (myself) and the projects the sources read. Each failure says why (API tokens expire...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account jira check
```

## Examples

```bash
playground account jira check
```
