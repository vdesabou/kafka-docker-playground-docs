# playground account jira

📋 Set up and check the Jira account of the Jira examples (connect-jira-source, fm-jira-source)

- **setup**: validate and store `JIRA_URL`, `JIRA_USERNAME` and `JIRA_API_TOKEN`
- **check**: verify them in a few seconds: the login (myself) and the projects the sources read

Nothing to configure in Jira: these examples only need the values,  
in the right form, still valid (API tokens expire).

📖 https://kafka-docker-playground.io/#/accounts

## Usage

```bash
playground account jira COMMAND
```

## Commands

- [check](playground%20account%20jira%20check) - 🩺 Check the Jira account of the Jira examples (connect-jira-source, fm-jira-source)
- [setup](playground%20account%20jira%20setup) - 🛠️ Validate and store the Jira account of the Jira examples (connect-jira-source, fm-jira-source)
