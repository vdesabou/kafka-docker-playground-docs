# playground account marketo check

🩺 Check the Marketo account of the Marketo examples (connect-marketo-source, fm-marketo-sink)

Read-only, a few seconds: the OAuth token of the LaunchPoint service and the leads API (603: missing API role). Each failure says why (sandboxes expire...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account marketo check
```
