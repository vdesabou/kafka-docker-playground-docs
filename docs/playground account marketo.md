# playground account marketo

📣 Set up and check the Marketo account of the Marketo examples (connect-marketo-source, fm-marketo-sink)

- **setup**: validate and store `MARKETO_ENDPOINT_URL`, `MARKETO_CLIENT_ID` and `MARKETO_CLIENT_SECRET`
- **check**: verify them in a few seconds: the OAuth token of the LaunchPoint service and the leads API (603: missing API role)

Nothing to configure in Marketo: these examples only need the values,  
in the right form, still valid (sandboxes expire).

📖 https://kafka-docker-playground.io/#/accounts

## Usage

```bash
playground account marketo COMMAND
```

## Commands

- [check](playground%20account%20marketo%20check) - 🩺 Check the Marketo account of the Marketo examples (connect-marketo-source, fm-marketo-sink)
- [setup](playground%20account%20marketo%20setup) - 🛠️ Validate and store the Marketo account of the Marketo examples (connect-marketo-source, fm-marketo-sink)
