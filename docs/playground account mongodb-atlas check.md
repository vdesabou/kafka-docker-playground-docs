# playground account mongodb-atlas check

🩺 Check the MongoDB Atlas account of the MongoDB Atlas examples (fm-mongodb-atlas-sink, fm-mongodb-atlas-source)

Read-only, a few seconds: the mongodb+srv record of the host and a ping with mongosh (mongo image). Each failure says why (M0 clusters pause after 60 days without connections...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account mongodb-atlas check
```

## Examples

```bash
playground account mongodb-atlas check
```
