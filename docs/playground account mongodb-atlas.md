# playground account mongodb-atlas

🍃 Set up and check the MongoDB Atlas account of the MongoDB Atlas examples (fm-mongodb-atlas-sink, fm-mongodb-atlas-source)

- **setup**: validate and store `MONGODB_ATLAS_HOST`, `MONGODB_ATLAS_USER` and `MONGODB_ATLAS_PASSWORD`
- **check**: verify them in a few seconds: the mongodb+srv record of the host and a ping with mongosh (mongo image)

Nothing to configure in MongoDB Atlas: these examples only need the values,  
in the right form, still valid (M0 clusters pause after 60 days without connections).

📖 https://kafka-docker-playground.io/#/how-to-use?id=%e2%98%81%ef%b8%8f-accounts-of-the-examples

## Usage

```bash
playground account mongodb-atlas COMMAND
```

## Commands

- [check](playground%20account%20mongodb-atlas%20check) - 🩺 Check the MongoDB Atlas account of the MongoDB Atlas examples (fm-mongodb-atlas-sink, fm-mongodb-atlas-source)
- [setup](playground%20account%20mongodb-atlas%20setup) - 🛠️ Validate and store the MongoDB Atlas account of the MongoDB Atlas examples (fm-mongodb-atlas-sink, fm-mongodb-atlas-source)
