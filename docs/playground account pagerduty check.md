# playground account pagerduty check

🩺 Check the PagerDuty account of the PagerDuty example (connect-pagerduty-sink)

Read-only, a few seconds: the service the incidents go to, and the user that sends them. Each failure says why (keys get revoked, services deleted...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account pagerduty check
```

## Examples

```bash
playground account pagerduty check
```
