# playground account pagerduty

🛎️ Set up and check the PagerDuty account of the PagerDuty example (connect-pagerduty-sink)

- **setup**: validate and store `PAGERDUTY_API_KEY`, `PAGERDUTY_SERVICE_ID` and `PAGERDUTY_USER_EMAIL`
- **check**: verify them in a few seconds: the service the incidents go to, and the user that sends them

Nothing to configure in PagerDuty: these examples only need the values,  
in the right form, still valid (keys get revoked, services deleted).

📖 https://kafka-docker-playground.io/#/how-to-use?id=%e2%98%81%ef%b8%8f-accounts-of-the-examples

## Usage

```bash
playground account pagerduty COMMAND
```

## Commands

- [check](playground%20account%20pagerduty%20check) - 🩺 Check the PagerDuty account of the PagerDuty example (connect-pagerduty-sink)
- [setup](playground%20account%20pagerduty%20setup) - 🛠️ Validate and store the PagerDuty account of the PagerDuty example (connect-pagerduty-sink)
