# playground account zendesk check

🩺 Check the Zendesk account of the Zendesk examples (connect-zendesk-source, fm-zendesk-source)

Read-only, a few seconds: the login (users/me, the `<email>`/token form) and the tickets the sources read. Each failure says why (a trial account ends after 14 days...)  
and which examples it breaks.

Exits with 1 when the login fails.

## Usage

```bash
playground account zendesk check
```

## Examples

```bash
playground account zendesk check
```
