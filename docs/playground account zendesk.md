# playground account zendesk

🎫 Set up and check the Zendesk account of the Zendesk examples (connect-zendesk-source, fm-zendesk-source)

- **setup**: validate and store `ZENDESK_URL`, `ZENDESK_USERNAME` and `ZENDESK_PASSWORD`
- **check**: verify them in a few seconds: the login (users/me, the `<email>`/token form) and the tickets the sources read

Nothing to configure in Zendesk: these examples only need the values,  
in the right form, still valid (a trial account ends after 14 days).

📖 https://kafka-docker-playground.io/#/how-to-use?id=%e2%98%81%ef%b8%8f-accounts-of-the-examples

## Usage

```bash
playground account zendesk COMMAND
```

## Commands

- [check](playground%20account%20zendesk%20check) - 🩺 Check the Zendesk account of the Zendesk examples (connect-zendesk-source, fm-zendesk-source)
- [setup](playground%20account%20zendesk%20setup) - 🛠️ Validate and store the Zendesk account of the Zendesk examples (connect-zendesk-source, fm-zendesk-source)
