# playground ansible inventory

📋 Read and change the inventory of the ansible environment

environment/ansible/inventory/hosts.yml, generated by the environment  
(or adapted from `--ansible-inventory`). Paths are yq paths, values are  
yaml (numbers, booleans, maps and lists keep their type). Changes are  
applied by the next `playground ansible playbook`.

## Usage

```bash
playground ansible inventory COMMAND
```

## Ansible commands

- [get](playground%20ansible%20inventory%20get) - 🔎 Display the inventory, or the value of a yq path
- [set](playground%20ansible%20inventory%20set) - ✏️ Set the value of a yq path, and print the change
- [delete](playground%20ansible%20inventory%20delete) - 🗑️ Remove a yq path from the inventory, and print the change
