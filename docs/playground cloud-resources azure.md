# playground cloud-resources azure

☁️ What is still running in Azure, and what it costs

- **list**: resources created by the playground, still alive
- **costs**: spend over a range of dates
- **costs-history**: spend per month over the last year

Uses the subscription your az CLI is logged into. Nothing is deleted  
here, use `playground cloud-resources cleanup` for that.

## Usage

```bash
playground cloud-resources azure COMMAND
```

## Commands

- [costs](playground%20cloud-resources%20azure%20costs) - 💰 Azure costs
- [costs-history](playground%20cloud-resources%20azure%20costs-history) - 👛 Azure costs for each month since last year
- [list](playground%20cloud-resources%20azure%20list) - 📋 List all active resources
