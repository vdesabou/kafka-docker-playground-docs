# playground cloud-resources nightly-cleanup status

🔎 Is the nightly cleanup scheduled, at what time, and what did its last runs do

## Usage

```bash
playground cloud-resources nightly-cleanup status [OPTIONS]
```

## Options

#### `--lines LINES`

📄 Number of lines of the log to show

| Attributes      | &nbsp;
|-----------------|-------------
| Default Value:  | `40`
