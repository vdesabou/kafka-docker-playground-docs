# playground codespace start

🟢 Start a codespace

Starts a stopped codespace and waits until it is available. 'open' and  
'ssh' start it too.

Without `--codespace`, the most recently used codespace is started.

## Usage

```bash
playground codespace start [OPTIONS]
```

## Options

#### `--codespace, -c CODESPACE`

☁️ codespace name, as shown by `playground codespace list` (use completion)

🎓 Tip: if not specified, the most recently used codespace is used
