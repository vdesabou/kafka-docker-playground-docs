# playground codespace sync-repro-folder codespace-to-local

👈 Sync a codespace reproduction-models folder to local

Brings back the models you wrote in the codespace. Run it before  
`playground codespace delete`, otherwise they go with the codespace.

Without `--codespace`, the most recently used codespace is used.

## Usage

```bash
playground codespace sync-repro-folder codespace-to-local [OPTIONS]
```

## Options

#### `--codespace, -c CODESPACE`

☁️ codespace name, as shown by `playground codespace list` (use completion)

🎓 Tip: if not specified, the most recently used codespace is used
