# playground config display-last-updated-connector-plugins-vendor

🏢 vendor of the connector plugins listed by display-last-updated-connector-plugins

Default is confluentinc. Use 'all' for every vendor.

## Usage

```bash
playground config display-last-updated-connector-plugins-vendor VENDOR
```

## Arguments

#### `VENDOR`

vendor

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

## Examples

```bash
playground config display-last-updated-connector-plugins-vendor debezium
```

```bash
playground config display-last-updated-connector-plugins-vendor all
```
