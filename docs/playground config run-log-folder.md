# playground config run-log-folder

🗂️ folder of the run logs

Default is ~/.local/state/kafka-docker-playground/run-logs.

The last 50 run logs of the folder are kept.

## Usage

```bash
playground config run-log-folder FOLDER
```

## Arguments

#### `FOLDER`

folder

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

## Examples

```bash
playground config run-log-folder ~/Documents/playground-run-logs
```
