# playground connector open-docs

🧑‍🎓 Open connector documentation of currently running connector(s)  
  
Works out the documentation page from the connector class actually  
running and opens it, so you land on the right page for the right  
connector without searching for it.  
  
Use --only-show-url to print the link instead, for pasting in a case.

## Usage

```bash
playground connector open-docs [OPTIONS]
```

## Options

#### *--only-show-url*

🌐 Only show url
