# playground connector versions

🧞 Get current and latest versions available on Confluent Hub for connector(s) used in example

Tells you in one line whether you are testing an outdated connector.  
To move to the version reported as latest, re-run the example with  
`playground update-version --connector-tag <version>`.

🍪 Deep dive: https://kafka-docker-playground.io/#/deep-dive-run-and-versions  
🎬 Bite size session: https://kafka-docker-playground.io/#/sessions?id=%F0%9F%8E%AF-is-it-fixed-in-a-newer-version

## Usage

```bash
playground connector versions
```
