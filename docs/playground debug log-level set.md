# playground debug log-level set

Set log level for specific logger  
  
Takes effect immediately and applies to the logger and everything  
below it in the package hierarchy.

## Usage

```bash
playground debug log-level set [OPTIONS]
```

## Options

#### *--package, -p PACKAGE*

📦 Package name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--level, -l LEVEL*

❕Log level

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes
| Allowed Values: | INFO, WARN, DEBUG, TRACE
