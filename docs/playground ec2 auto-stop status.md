# playground ec2 auto-stop status

🔎 Is the auto-stop scheduled, at what time, and what did its last runs do

## Usage

```bash
playground ec2 auto-stop status [OPTIONS]
```

## Options

#### `--lines LINES`

📄 Number of lines of the log to show

| Attributes      | &nbsp;
|-----------------|-------------
| Default Value:  | `40`
