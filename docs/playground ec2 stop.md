# playground ec2 stop

🔴 Stop an EC2 instance  
  
Shuts the instance down while keeping its disk, so you stop paying for  
compute and find your work again on 'playground ec2 start'.

## Usage

```bash
playground ec2 stop [OPTIONS]
```

## Options

#### *--instance, -i INSTANCE*

🖥️ ec2 instance (need to use completion to get all required details)  
  
🎓 Tip: If not specified, the command will apply to all ec2 instances
