# playground re-run

⚡ Simply re-run last example you ran with `<playground run>`

Same script and same flags as last time: the `--tag`, `--connector-tag`,  
`--connector-zip` and `--enable-*` you picked are replayed from playground.ini,  
so there is nothing to retype after a code change.

🎓 Tip: to re-run with a different version, use `playground run` again and  
change the flag, or `playground update-version` on the running example.

🍪 Deep dive: https://kafka-docker-playground.io/#/deep-dive-run-and-versions  
🎬 Bite size session: https://kafka-docker-playground.io/#/sessions?id=%F0%9F%95%B9%EF%B8%8F-run-an-example-with-the-menu-or-with-flags

## Usage

```bash
playground re-run
```

visit https://github.com/junegunn/fzf#installation to install
