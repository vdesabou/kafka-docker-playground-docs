# playground salesforce

☁️ Set up a Salesforce org for the Salesforce examples, and check it

- **setup**: configure an org: External Client App (JWT bearer), Platform Event, Change Data Capture
- **check**: verify that the stored credentials can log in, and that the org has what the examples need

Replaces the manual steps of the Salesforce example READMEs. Only signing  
up for the Developer Edition org stays manual.

## Usage

```bash
playground salesforce COMMAND
```

## Commands

- [setup](playground%20salesforce%20setup) - 🛠️ Configure a Salesforce org for the Salesforce examples
- [check](playground%20salesforce%20check) - 🩺 Check that the stored Salesforce credentials work
