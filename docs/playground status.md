# playground status

🗺️ Show a status  
  
A single screen answering "what is running right now, and is it healthy":  
the example currently running and its documentation link, the state of  
every container (flagging the exited or restarting ones), the version of  
every connector, the status and configuration of each of them, the topics  
that exist, and whether an EC2 instance of yours is still up.  
  
Everything comes from the running containers and from playground.ini, so  
it is also the quickest way to get back your bearings after a break.

## Usage

```bash
playground status
```
