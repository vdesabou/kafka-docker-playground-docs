# playground streams

🌊 Kafka Streams commands

Look at the Kafka Streams applications of the running example (the  
instances of other/kafka-streams, or the Streams containers of a  
reproduction model), from what the Kafka Streams library logs and from  
their consumer group: no JMX, no code in the application.

- **status**: state of each instance, rebalances, threads, active and standby tasks, restoration, known errors

🎓 Tip: the same Kafka Streams view of a customer's log files is in  
`playground analyze logs` (🌊 Kafka Streams section).

## Usage

```bash
playground streams COMMAND
```

## Kafka Streams commands

- [status](playground%20streams%20status) - 🌊 Show the state of the Kafka Streams instances
