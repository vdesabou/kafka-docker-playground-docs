# playground switch-docker

🐳 Switch the container engine back to Docker  
  
Restores the docker context that was active before 'playground switch-podman'  
(Docker Desktop's 'desktop-linux', or 'default', if none was remembered).  
Ends with 'playground doctor'.  
  
Containers are not moved between engines: stop the running example first.

## Usage

```bash
playground switch-docker
```

## Examples

```bash
playground switch-docker
```
