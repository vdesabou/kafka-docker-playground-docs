# playground tcp-proxy close-all-connection-with-error

🧹 Close all Zazkia TCP connections which are in error state  
  
Same as the "close all with error" button in the Zazkia UI. Connections  
left behind by a previous break or delay clutter get-connections;  
this cleans them up so you only see the live ones.

## Usage

```bash
playground tcp-proxy close-all-connection-with-error
```
