# playground tcp-proxy open-ui

🌐 Just open Zazkia UI (http://localhost:9191) in your browser  
  
The UI shows the same connections as get-connections, but live, with  
the toggles as buttons and a diagram of which direction each one cuts.  
Easier than the CLI when you are exploring, the CLI is what you put in  
a reproduction script once you know which fault you want.

## Usage

```bash
playground tcp-proxy open-ui
```
