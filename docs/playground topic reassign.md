# playground topic reassign

🔀 Move the replicas of a topic to other brokers

Wraps kafka-reassign-partitions, to reproduce a partition  
reassignment or a rebalance (needs several brokers: playground run  
`--enable-multiple-brokers`, brokers 1, 2 and 3). Set one of:

- `--replicas 2`, `3`: the replicas of every partition (or of `--partition`): the first one is the preferred leader
- `--brokers 1`, `2`, `3`: a balanced plan over these brokers, generated by kafka-reassign-partitions `--generate` (same replication factor)

Displays the current and the new assignment, executes it, and waits  
until the reassignment is completed (kafka-reassign-partitions  
`--verify`, which also removes the `--throttle`). The leaders only move to  
the new preferred replicas after a leader election: see 'playground  
topic elect-leader'.

🎓 Tip: `--throttle` limits the replication traffic of the move, to  
keep a reassignment running for a while (under-replicated  
partitions, clients refreshing their metadata).

## Usage

```bash
playground topic reassign [OPTIONS]
```

## Options

#### `--topic, -t TOPIC`

🗳 Topic name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### `--partition, -p PARTITION`

🔢 Only reassign this partition (with `--replicas`)

#### `--replicas REPLICAS`

🖥️ Comma separated broker ids of the replicas, preferred leader first (e.g. 2,3)

| Attributes      | &nbsp;
|-----------------|-------------
| Conflicts With: | `--brokers`

#### `--brokers BROKERS`

⚖️ Comma separated broker ids to spread the partitions over (e.g. 1,2,3)

| Attributes      | &nbsp;
|-----------------|-------------
| Conflicts With: | `--replicas`, `--partition`

#### `--throttle BYTES`

🐢 Replication throttle during the move, in bytes per second

#### `--dry-run`

🧪 Only display the current and new assignment

#### `--no-wait`

⏩ Do not wait for the reassignment to complete (check it again with the same command and `--verify-only`)

#### `--verify-only`

🔎 Only display the progress of a reassignment started with `--no-wait` (and remove its throttle when it is completed)

#### `--max-wait MAX-WAIT`

⏳ Maximum time to wait for the reassignment, in seconds (default 300)

| Attributes      | &nbsp;
|-----------------|-------------
| Default Value:  | `300`

#### `--verbose, -v`

🐞 Show command being ran.

## Examples

```bash
playground topic reassign --topic orders --replicas 2,3
```

```bash
playground topic reassign --topic orders --partition 0 --replicas 3,1,2
```

```bash
playground topic reassign --topic orders --brokers 1,2,3 --throttle 1024 --dry-run
```
