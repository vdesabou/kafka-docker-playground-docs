# playground topic tag add

🏷️ Assign a tag to a topic

## Usage

```bash
playground topic tag add [OPTIONS]
```

## Options

#### *--topic, -t TOPIC*

🗳 Topic name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--tag TAG*

🏷️ Tag name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag add --topic pageviews --tag PII
```
