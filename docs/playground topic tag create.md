# playground topic tag create

🆕 Create a tag definition

## Usage

```bash
playground topic tag create [OPTIONS]
```

## Options

#### *--tag TAG*

🏷️ Tag name (letters, digits and underscores, starting with a letter)

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--description DESCRIPTION*

📝 Tag description

| Attributes      | &nbsp;
|-----------------|-------------
| Default Value:  | 

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag create --tag PII --description "Personally identifiable information"
```
