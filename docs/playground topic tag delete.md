# playground topic tag delete

❌ Delete a tag definition  
  
The tag must not be assigned to any topic anymore.

## Usage

```bash
playground topic tag delete [OPTIONS]
```

## Options

#### *--tag TAG*

🏷️ Tag name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag delete --tag PII
```
