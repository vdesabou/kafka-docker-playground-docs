# playground topic tag remove

🧽 Remove a tag from a topic

## Usage

```bash
playground topic tag remove [OPTIONS]
```

## Options

#### *--topic, -t TOPIC*

🗳 Topic name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--tag TAG*

🏷️ Tag name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag remove --topic pageviews --tag PII
```
