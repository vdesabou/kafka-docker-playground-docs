# playground topic tag search

🔎 Search topics having a tag

## Usage

```bash
playground topic tag search [OPTIONS]
```

## Options

#### *--tag TAG*

🏷️ Tag name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag search --tag PII
```
