# playground topic tag show

🔎 Show tags assigned to a topic

## Usage

```bash
playground topic tag show [OPTIONS]
```

## Options

#### *--topic, -t TOPIC*

🗳 Topic name

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *--verbose, -v*

🐞 Show command being ran.

## Examples

```bash
playground topic tag show --topic pageviews
```
